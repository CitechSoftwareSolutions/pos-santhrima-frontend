# POS Keyboard Shortcuts — Cashier Quick Guide

This guide describes the keyboard shortcuts available on the Point of Sale (`/pos`) terminal. Shortcuts are designed to keep transactions lightning fast while completely avoiding accidental triggers during barcode scanning or typing.

---

## ⚡ The Two-Layer System

1. **Bare Keys (e.g. `W`, `R`, `C`, `D`)**
   - Active when focus is **outside** of any text box or dialog.
   - Lets you instantly filter categories or switch tools with a single keystroke.
2. **Alt + Key (e.g. `Alt+W`, `Alt+S`, `Alt+C`)**
   - Works **anywhere**, even while your cursor is inside the search box.
   - Holding down <kbd>Alt</kbd> lights up all shortcut badges on screen.

> **Sinhala & Tamil Keyboards:** Shortcuts match physical key positions (`event.code`), so you don't need to switch keyboard layouts or turn off your IME.

## 📋 Complete Shortcut Reference

### 1. Categories
| Key | Alt Shortcut | Action | Notes |
| :--- | :--- | :--- | :--- |
| <kbd>A</kbd> | <kbd>Alt</kbd> + <kbd>A</kbd> | All Categories | Resets category filter |
| <kbd>R</kbd> | <kbd>Alt</kbd> + <kbd>R</kbd> | Retail | Filters to Retail items |
| <kbd>M</kbd> | <kbd>Alt</kbd> + <kbd>M</kbd> | Measurable | Filters to Measurable items |
| <kbd>W</kbd> | <kbd>Alt</kbd> + <kbd>W</kbd> | Wholesale | Filters to Wholesale items |
| *Dynamic* | <kbd>Alt</kbd> + *Key* | Custom Category | Assigned from first available letter or digits 1–9 |

### 2. Search & Product Navigation
| Key | Shortcut | Action |
| :--- | :--- | :--- |
| <kbd>/</kbd> or <kbd>F2</kbd> | <kbd>Alt</kbd> + <kbd>S</kbd> | Focus Product Search (selects existing text) |
| <kbd>↓</kbd> (from search) | — | Move focus into the product grid |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | — | Navigate between product cards in the grid |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | — | Open Add-to-Cart dialog for the selected product |
| Barcode + <kbd>Enter</kbd> | — | Direct barcode scan lookup and add to cart |
| <kbd>Esc</kbd> *(1st press)* | — | Clears text in search box |
| <kbd>Esc</kbd> *(2nd press)* | — | Blurs search box (returns focus to hotkey mode) |

### 3. Add-to-Cart Dialog
| Key | Shortcut | Action |
| :--- | :--- | :--- |
| *Auto-focus* | — | Quantity field is automatically focused with text highlighted |
| <kbd>+</kbd> / <kbd>-</kbd> | — | Increase or decrease quantity |

### 4. Cart & Billing

## 💡 Cashier Tips
- **Fast Flow:** <kbd>/</kbd> (type product) → <kbd>↓</kbd> → <kbd>Enter</kbd> → (type quantity) → <kbd>Enter</kbd> → <kbd>F9</kbd> (charge).
- **Hold <kbd>Alt</kbd>:** Whenever in doubt, press and hold <kbd>Alt</kbd> to see all available shortcut badges brighten on screen.
- **Toggle Hints:** In the cheat-sheet (<kbd>?</kbd>), you can toggle shortcut badge visibility on or off based on personal preference.
